PHASE 0 — Fresh OpenHands Installation (March 2026)

Objective: Get a stable, self-testing base running on Bryan’s hardware in under 2 hours.

EXACT SETUP INSTRUCTIONS (Windows 11 Pro + Ryzen 5 5600X + RTX 3060 12 GB + 32 GB RAM)

1. Enable WSL2 (required for stable sandbox)
   Open PowerShell as Administrator and run:
   wsl --install
   wsl --set-default-version 2

2. Install Docker Desktop (sandbox isolation)
   Download: https://www.docker.com/products/docker-desktop/
   Run installer → enable WSL2 backend during setup → reboot

3. Install Git
   Run in PowerShell (admin):
   winget install --id Git.Git -e --source winget

4. Install Ollama (local LLM engine – stay with this)
   Download: https://ollama.com/download/OllamaSetup.exe
   Run installer
   Open terminal and pull a starter model:
   ollama pull llama3.1:8b
   ollama serve   (leave this running in background)

5. Create new project folder
   mkdir E:\AI_Lab_New
   cd E:\AI_Lab_New

6. Clone OpenHands
   git clone https://github.com/All-Hands-AI/OpenHands.git
   cd OpenHands

7. Install dependencies (recommended: use Poetry)
   winget install Python.Python.3.12
   pip install poetry
   poetry install

8. Configure Ollama in OpenHands
   Create file config.toml in the OpenHands root folder with this content:
   [llm]
   model = "ollama/llama3.1:8b"
   base_url = "http://localhost:11434"

9. First test run
   poetry run python -m openhands.main
   (OpenHands GUI will start at http://localhost:3000 – open in browser to confirm working)
