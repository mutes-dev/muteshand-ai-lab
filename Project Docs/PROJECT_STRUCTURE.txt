# DATA FLOW (SOURCE OF TRUTH)

User Input (string)
→ Planner (structure only)
→ Parser (numeric + quoted string extraction)
→ Resolver (positional mapping)
→ Entry (orchestration)
→ Validation (FAIL-FAST — blocks invalid plans)
→ Execution (runtime — only valid plans, single-step)
→ Result

## ⚠️ EXECUTION LAYER NOTE (IMPORTANT)

Execution lives in:

/system/execution/executor.py

Manager is LEGACY ONLY and deprecated.

---

### EXECUTION BEHAVIOR

Execution is:

- deterministic
- step-based
- isolated in execution module
- performs output normalization (PERMANENT)
- includes argument guard (TEMPORARY)

Output Normalization:
- Contract tools: unwraps {"status": "success", "result": ...} → extracts result
- Raw tools: wraps raw value → {"status": "success", "result": raw_value}

→ add 2 and 3 then multiply the result by 4

* deterministic substitution

* NO NLP

# SEMANTIC MAPPING LAYER

## LOCATION

## PURPOSE
