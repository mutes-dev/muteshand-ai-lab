## ARCHITECTURAL OBSERVATIONS

### Verified Divergences from Original Structure

1. **`core/` exists as a real layer** — Original structure barely mentioned it. It contains 13+ files including a full pipeline (planner, parser, resolver, executor, validation). This is a significant architectural layer that needs explicit authority mapping.

2. **`system/validation/` is empty** — Validation logic appears split between `core/validation.py`, `system/orchestrator/validator.py`, and `system/observability/validator.py`. There is no unified validation layer.

3. **`system/tests/` is empty** — Tests are all in root `tests/`. The intended `system/tests/` separation does not exist.

4. **`system/interface/` exists** — Not in original structure. Contains event bus, emitter, notification manager.

5. **`system/memory/` exists** — Not in original structure. Contains global memory, memory adapter, preference tracker.

6. **`system/runtime/` exists** — Not in original structure. Contains background manager.

7. **`system/trace_utils/` exists** — Not in original structure. Contains decision viewer, retry analyzer, step timeline viewer.

8. **`system/checkpoints/` exists** — Not in original structure. Contains 70+ workflow checkpoint files.

9. **`memory/tool_index/` is empty** — The actual tool index is in `system/tool_index/`.

10. **`system/config/` exists** — Not in original structure. Contains tool exposure config.

11. **`ORCHESTRATOR_CONTRACT.txt` in-place** — Superseded by `ORCHESTRATOR_CONTRACT_V2.txt` in Project Docs, but the old file remains in orchestrator directory.

12. **`core/chain_resolver.py` exists** — Chain resolution was declared removed, but the file still exists.

### Authority Concerns (for audit)

- `core/` and `system/` both contain planner, parser, resolver, executor, validation modules. This is a potential authority duplication.
- `system/orchestrator/` has 40+ files. Many may be doing work that belongs to other layers (memory, persistence, projection).
- `system/interface/` may be synthesizing events that could leak into lifecycle authority.
