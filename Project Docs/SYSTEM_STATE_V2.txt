## 2. CURRENT VERIFIED ARCHITECTURE STATE

### Authority Chain (Verified)
```
execution_result → governance → lifecycle authority → persistence → projection → frontend
```

### Verified Boundaries
- **Execution boundary**: Absolute. Orchestrator → system_entry ONLY.
- **Governance authority**: Sole decision maker for retry/fail/complete/escalate.
- **Validator isolation**: Advisory-only. Zero governance influence.
- **Lifecycle authority**: Runtime registry (`_workflow_state_registry`) is sole owner.
- **Projection model**: Read-model only. Must not synthesize lifecycle truth.
- **Frontend model**: Projection-only renderer.

### Verified Runtime Semantics
- Pause is cooperative/deferred (completes active step first)
- Retry is governance-authorized only
- Dependency evaluation uses live step state over stale snapshots
- Projections are eventually consistent; temporary lag is valid
- Derived artifacts (tool_call, scheduler snapshots, projection caches) are mutable operational state, NOT semantic truth
