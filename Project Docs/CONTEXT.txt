# 🧱 SYSTEM ARCHITECTURE (FINAL)

The system is a **layered pipeline**:

User Input
→ Planner (LLM — structure only)
→ Parser (tokens)
→ Argument Resolver (arguments)
→ Chain Resolver (dependency injection)
→ Validation (structure only)
→ Execution (deterministic runtime)
→ Result

---

## 🔒 HARD RULES

* Planner MUST NOT generate arguments
* Parser ONLY generates tokens
* Argument Resolver creates arguments
* Chain Resolver injects dependencies
* Validation checks structure ONLY
* Execution performs runtime ONLY

NO layer may take another layer’s responsibility.

## 🔧 IMPLEMENTED LAYERS

### Planner

* Generates structured steps
* Uses LLM
* Handles retries
* Returns plan OR failure object
* Includes deterministic input normalization (pre-processing)

---

### Parser

* Deterministic tokenizer
* Returns list of tokens
* No interpretation

---

### Argument Resolver (LOCKED)

* Converts tokens → numeric arguments
* Removes filler words
* No inference
* Deterministic

---

### Chain Resolver (LOCKED)

* Replaces PREVIOUS_RESULT
* Uses execution results
* Enforces single dependency
* Raises errors on misuse

---

### Validation

* Schema validation
* Tool existence
* Argument count check
* HARD GATE (blocks execution)

---

### Execution

* Executes tools
* Stores results
* No reasoning
* No correction

NO:

* hidden recovery

This is an intentional transitional state during modularization.

Execution responsibilities currently handled in manager:

* argument handling

### 🔒 CRITICAL CONSTRAINTS

## 🔧 INPUT NORMALIZATION LAYER (PLANNER PRE-PROCESSING)

A deterministic normalization step exists in planner:

core/planner.py → normalize_input_text()

---

### PURPOSE

Convert implicit chained instructions into explicit form:

Example:
add 2 and 3 then multiply by 4
→ add 2 and 3 then multiply the result by 4

---

### IMPLEMENTATION MODEL

Normalization uses:

* clause splitting (" then ")
* fixed token structure matching
* strict positional validation

---

### 🔒 CONSTRAINTS

* NO regex
* NO pattern matching
* NO interpretation
* NO flexible matching

---

### ⚠️ IMPORTANT

This is NOT parsing or NLP.

This is deterministic structural transformation ONLY.
