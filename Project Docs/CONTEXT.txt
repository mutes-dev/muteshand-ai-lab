## LLM BEHAVIOR MODES

The system operates in TWO modes:

MODE 1 — SAFE MODE (NO ENV):
- LLM_MODEL not set
- Adapter returns failure
- llm_entry returns input_text (passthrough)

- LLM_MODEL is set
- LLM adapter executes LLM call
- Output parsed and validated
- Returns structured plan (list of steps)
- Invalid output → guaranteed fallback to deterministic planner
