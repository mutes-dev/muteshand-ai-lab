## CLASSIFICATION DEFINITIONS

### ACTIVE_AUTHORITY
Current runtime truth / architecture authority only. These documents define what the system IS and how it MUST behave.

### ACTIVE_OPERATIONAL
Current execution/checklist/operational docs. These track state, issues, decisions, and implementation status.

### RECONCILIATION_REFERENCE
Audit artifacts useful for future verification. These provide evidence of past reconciliation but do not define current runtime truth.

### HISTORICAL_REFERENCE
Useful context but MUST NOT drive runtime truth. These documents informed past decisions but are not current authority.

### SUPERSEDED
Explicitly replaced by newer authority. Must NOT be used for runtime truth interpretation.

### NON_AUTHORITATIVE
Personal prompts, operational scratch docs, temporary coordination artifacts. No architectural or runtime authority.

## CONTAMINATION RISK MATRIX

| Risk | Source | Mitigation |
|------|--------|------------|
| ROADMAP_V2_TEMP driving runtime truth | Outdated layer labels | Classification: SUPERSEDED. DECISION_LOG_V2 explicitly demotes it. |
| Historical audit overriding current state | Archive/ documents | Classification: HISTORICAL_REFERENCE. Runtime truth is SYSTEM_STATE_V2. |
| Reconciliation audit becoming new authority | *_RECONCILIATION_AUDIT_V1.txt | Classification: RECONCILIATION_REFERENCE. Evidence only, not runtime truth. |
| Prompt/template misinterpreted as authority | *_PROMPT.txt, *_TEMPLATE.txt | Classification: NON_AUTHORITATIVE. |

---

## MAINTENANCE RULES

- New contracts default to ACTIVE_AUTHORITY
- New audit artifacts default to RECONCILIATION_REFERENCE
- Resolved/superseded documents move to SUPERSEDED, not deleted
- Roadmaps and planning documents default to HISTORICAL_REFERENCE after completion
- Prompts and templates default to NON_AUTHORITATIVE
- Only SYSTEM_STATE_V2, DECISION_LOG_V2, KNOWN_ISSUES_V2, and MASTER_IMPLEMENTATION_CHECKLIST may be ACTIVE_OPERATIONAL
- Reclassification requires DECISION_LOG_V2 entry
