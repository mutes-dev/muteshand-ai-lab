## 8. DRIFT REMEDIATION TRACKING

### Drift Classification Model

| Category | Description | Example |
|----------|-------------|---------|
| Authority Drift | Implementation violates authority ownership | Derived layer acts authoritative |
| Sequencing Drift | Ordering violates orchestration contracts | Retry occurs before terminalization completes |
| Convergence Drift | Synchronization violates downward-only rule | Projection reconciles upward into lifecycle |
| Recovery Drift | Replay leakage, projection bootstrap, stale resurrection | Recovery replays execution automatically |
| Mutation Drift | Illegal concurrent mutation, ACTIVE mutation leakage | Mutation during ACTIVE execution |
| Projection Drift | Frontend synthesis, stale projection overwrite | GUI infers workflow state from projection |
| Runtime Coordination Drift | Stale worker continuation, orphan leakage | Orphan execution continues without authority |
| Persistence Drift | Persistence-derived authority, upward reconciliation | Stale snapshot restored as lifecycle truth |
