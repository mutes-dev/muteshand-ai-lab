# AI LAB — TEST CASES (BASELINE)

---

## CORE PRINCIPLE

Tests validate:

✔ Deterministic behavior
✔ Architecture integrity
✔ Correct failure handling

Tests DO NOT:

❌ enforce intelligence
❌ require planner perfection
❌ bypass architecture

---

# 🧪 TEST CATEGORIES

---

## 1. EXECUTION LAYER TESTS

---

### TEST 1 — BASIC ADD

Input:
add 2 and 3

Expected:
✔ success
✔ result = 5

---

### TEST 2 — BASIC MULTIPLY

Input:
multiply 2 and 3

Expected:
✔ success
✔ result = 6

---

### TEST 3 — CHAINED OPERATION (PHASE 1 BEHAVIOR)

Input:
add 2 and 3 then multiply by 4

Expected:

✔ EITHER:

A) success (correct chaining achieved)
→ result = 20

OR

B) deterministic failure
→ validation failure OR retry exhaustion

---

### TEST 4 — PREVIOUS_RESULT CHAINING

Input:
add 2 and 3 then multiply the result by 4

Expected:

✔ EITHER:

A) success
→ result = 20

OR

B) deterministic failure

---

## 🔒 RULE (CRITICAL)

For chained tests:

> FAILURE is VALID if:

* no crash
* no invalid execution
* failure is explicit

# 🧠 VALIDATION RULES

---

## SUCCESS CRITERIA

A test PASSES if:

✔ Output matches expected result
✔ OR valid failure is returned

---

## FAILURE CRITERIA

A test FAILS if:

❌ system crashes
❌ exception escapes
❌ incorrect success returned
❌ hidden failure occurs

---

# ⚠️ IMPORTANT NOTE

Tests MUST NOT:

❌ force planner intelligence
❌ expect perfect chaining
❌ assume correct tool selection
