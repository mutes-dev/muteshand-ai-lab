## 1. Purpose

This contract formalizes:
- bounded agent governance semantics
- agent containment rules
- governance interaction boundaries
- semantic signal classification
- execution authority prohibitions
- escalation requirements
- centralized orchestration preservation

This contract governs:
bounded AG1 governance posture.

This contract does NOT:
- redesign governance
- introduce autonomous agents
- introduce multi-agent orchestration
- operationalize adaptive orchestration
- reinterpret semantic systems as authoritative

---

## 2. AG1 Governance Philosophy

AG1 agents are:
bounded intelligence infrastructure.

NOT:
runtime authority infrastructure.

---

## Agents MAY

- recommend
- interpret
- classify
- suggest
- assist
- route through authorized orchestration pathways

## Agents MAY NOT

- own runtime authority
- own lifecycle authority
- own execution authority
- mutate authoritative runtime state directly
- override execution_result
- trigger retries independently
- approve mutations
- bypass governance
- claim convergence authority
- claim replay identity authority

---

## 3. Signal vs Authority Model

Agent outputs are:
semantic signals.

NOT:
authoritative execution truth.

---

## Authoritative Runtime Truth

execution_result owns execution truth.

Governance owns runtime decisions within the broader authority chain.

Lifecycle Authority owns lifecycle truth.

Runtime Registry owns execution coordination state.

## Semantic Signal Classification

| Signal Source | Classification | Authority |
|-------------|----------------|-----------|
| execution_result | authoritative truth | HIGH |
| validator (rule-based) | support | MEDIUM |
| validator (LLM) | weak signal | LOW |
| agent outputs | semantic signal | LOW |
| planner outputs | structure only | NONE |

---

## Explicit Prohibitions

Semantic systems (agents, planners, validators, LLM signals) MUST NOT:

- override execution_result
- directly mutate runtime state
- claim lifecycle authority
- claim execution identity ownership
- bypass governance decision flow
- originate replay/reconstruction truth

---

## 4. Centralized Orchestration Requirement

## Canonical AG1 Topology

```
Operator / Workflow
↓
Central Orchestrator
↓
Governance / Mutation Legality
↓
Bounded Agent Services (signals only)
↓
system_entry
↓
Execution Runtime
↓
execution_result
```

---

## Routing Requirement

All agent activity MUST route through:
centralized orchestration.

Agents MUST NOT:
- coordinate orchestration independently
- establish parallel orchestration pathways
- create distributed decision nodes
- own orchestration sequencing

---

## 5. Allowed AG1 Capabilities

Explicitly allowed within AG1:

- stateless typed agents
- bounded tool-selection agents
- advisory semantic systems
- specialized planners (structure-only)
- governance-bounded recommendation systems
- semantic interpretation helpers
- validation assistants
- semantic observability helpers

All systems above remain:
non-authoritative.

## 6. Prohibited AG1 Capabilities

Explicitly prohibited within AG1:

- persistent agent identity
- autonomous orchestration ownership
- agent-owned lifecycle transitions
- agent-owned retries
- agent-owned mutation legality
- agent-owned runtime authority
- self-modifying planners
- unrestricted adaptive systems
- multi-agent orchestration
- distributed semantic coordination
- semantic execution authority
- execution_result override
- semantic truth ownership

## 7. Governance Integration Rules

## Agent Interaction Model

Agents MAY:
- provide advisory recommendations
- provide semantic analysis
- provide bounded planning suggestions

Governance MAY:
- authorize agent-provided signals
- reject agent-provided signals
- constrain agent-provided signals
- ignore agent-provided signals

---

## Bypass Prohibitions

Agent outputs MUST NOT bypass:
- governance
- mutation legality
- lifecycle authority
- execution identity rules
- runtime coordination rules

- persistent agent memory ownership

These domains are OUTSIDE AG1 scope.
