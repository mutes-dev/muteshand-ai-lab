## [RESOLVED — VALIDATION PLACEHOLDER BUG]

Issue:
Validation incorrectly treated PREVIOUS_RESULT as a literal value.

Fix:
Validation now skips runtime placeholder tokens.

Result:
- Restored correct phase separation
- Prevented false validation failures
- Enabled deterministic multi-step execution

---

## [RESOLVED — P0]

Issue:
Chain Resolver was incorrectly placed before validation,
causing dependency resolution to fail due to missing execution data.

Root Cause:
Incorrect assumption that dependency resolution is a static pipeline stage.

Fix:
Moved Chain Resolver into execution loop as a runtime dependency injector.

Result:
- Correct execution order
- Proper dependency resolution
- Deterministic multi-step execution restored
