**Fix Required:**
- Add `workflow_id` to execution_result (safe, non-breaking addition)
- OR return it as a separate field alongside execution_result

### 2. No Trace Retrieval API Endpoint
There is no `/trace/{workflow_id}` endpoint in `api.py`.

**Fix Required:**
- Add GET endpoint: `/trace/{workflow_id}`
- Implement trace storage lookup by workflow_id
- Currently trace is in-memory only — need persistent storage or cache

### 3. Trace Persistence Gap
Trace exists only in-memory. Once execution completes and process exits, trace is lost.

**Fix Required (Optional):**
- Persist trace to disk (e.g., `traces/{workflow_id}.json`)
- OR keep recent traces in memory with LRU cache
- OR stream trace to external observability system

### 4. Global Collector Limitation
`_active_collector` is a singleton. Only the most recent workflow's trace is accessible.

**Fix Required:**
- Store collectors in a dict keyed by workflow_id
- OR persist trace before collector is destroyed
