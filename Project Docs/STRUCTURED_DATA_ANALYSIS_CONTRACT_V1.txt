------------------------------------------------------------
1. Purpose
------------------------------------------------------------

StructuredDataAnalysisProfile governs bounded deterministic local CSV/XLSX analysis.

The profile is for one-file, one-table/worksheet, bounded structured-data analysis where the input data has already been acquired or can be acquired through approved local readers.

The profile supports deterministic structured-data operations such as:

- row count;
- max;
- min;
- sum;
- average;
- deterministic associated-row lookup for max/min only when supported by evidence and approved implementation design.

The profile is not a broad spreadsheet intelligence system.

------------------------------------------------------------

12. Evidence and result expectations
------------------------------------------------------------

Structured-data analysis outputs must be evidence-backed.

Minimum result should include:

- status;
- operation;
- input file/source identity;
- sheet/table identity where applicable;
- column refs used;
- row refs used where applicable;
- cell refs used where applicable;
- computed value;
- associated row/entity where applicable and supported;
- unsupported/ambiguous/not_found status where applicable;
- limitations/warnings;
- validator results where available.

Allowed statuses:

- success
- not_found
- ambiguous
- unsupported
- blocked
- failed

Numeric results must be grounded in table/column/cell references where applicable.

If the requested column/table/sheet cannot be resolved deterministically, return ambiguous/not_found/unsupported rather than guessing.

------------------------------------------------------------
13. Safe unsupported outcomes
------------------------------------------------------------

Unsupported structured-data requests must fail safely with honest output.

Examples of unsupported requests:

- arbitrary workbook analysis;
- "analyze this spreadsheet" with no bounded operation;
- formula execution;
- macro execution;
- pivot interpretation;
- chart/image interpretation;
- multi-file joins;
- cross-sheet relational analysis outside accepted scope;
- document Q&A;
- web + table mixed workflows unless separately handled through F4-style resolution;
- arbitrary natural-language table reasoning;
- LLM-generated code execution.

The system must not fake numeric answers.

The system must not produce a confident answer when evidence is missing.

The system must not silently fall back to GeneralFallbackProfile to attempt unsupported analysis.
