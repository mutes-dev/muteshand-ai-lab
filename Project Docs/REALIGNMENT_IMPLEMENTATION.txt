## PHASE 2 — ORCHESTRATOR CONTROL LAYER

Status: BUILT — HEAVILY TANGLED

What exists:

- orchestrator_runtime.py — run_workflow + execute_from_input (1065 lines)
- orchestrator_planner.py — LLM-based workflow planning
- agent_executor.py — agent execution with LLM
- task_classifier.py — rule-based + keyword classification
- workflow_validator.py — workflow structure validation
- memory_controller.py — runtime context management
- escalation_controller.py — retry + escalation handling
- user_control.py — pause/resume/override
- user_approval.py — approval gate (placeholder)
- persistence.py — workflow save
- planner_soft_guard.py — atomic step enforcement

Issues:

- orchestrator_runtime.py is monolithic (1065 lines)
  - mixes: step selection, agent execution, validation, result propagation,
    chaining logic, constraint extraction, trace capture, governance calls
  - should be decomposed into focused modules
- agent_executor.py directly calls system_entry
  - correct per contract, but agent output (USE_TOOL:) prefix stripping
    is buried inside agent_executor, not a clean conversion layer
- operand injection logic in runtime (lines 344-386) is runtime intelligence
  - violates separation: runtime should not parse purpose strings
- constraint extraction via LLM happens in runtime (extract_constraints_llm)
  - LLM calls inside runtime loop violate deterministic control principle
- duplicate function: inject_result_into_purpose defined twice (lines 36-49)
- step schema does not match STEP_SCHEMA_CONTRACT_V1
  - missing: type, purpose, tool_call, expected_outcome, risk, importance, resource_targets
  - current steps only have: id, name, agent, status, retries, max_retries, input
- workflow built in main.py (build_workflow) uses minimal schema
  - no classification, risk, importance, or purpose fields
- no project system — single workflow per execution
  - no project states (QUEUED, ACTIVE, PAUSED, BLOCKED, COMPLETED, FAILED)
  - workflow["status"] used but not aligned with STATE_TRANSITIONS_CONTRACT

Issues:

- no confidence model implemented

- no approval integration in governance

- governance does not return BLOCK decision
  - only returns: retry, complete, escalate, fail
  - CONTRACT defines: COMPLETE, RETRY, FAIL, BLOCK, ESCALATE
