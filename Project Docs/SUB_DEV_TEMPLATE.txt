## 🤖 LLM AWARENESS (CRITICAL)

The system includes an OPTIONAL LLM layer.

### DUAL-MODE SYSTEM

SAFE MODE (default):
- No LLM_MODEL configured
- System is fully deterministic
- llm_entry returns input_text (passthrough)

INTELLIGENT MODE (env-enabled):
- LLM_MODEL configured
- LLM adapter generates structured plans
- Output is validated before execution

### SUB DEV RULES FOR LLM

LLM output is NON-AUTHORITATIVE.

- LLM is used for reasoning in the Orchestrator (HAND) layer
- LLM must be guided, not blindly restricted
- Deterministic layers remain authoritative for execution truth

### CONSTRAINT

Sub Dev MUST NOT:
- assume LLM is available
- depend on LLM for deterministic behavior
- validate LLM output at execution layer

---

## 🚨 OVER-CONSTRAINT PREVENTION

- forcing deterministic output selection in synthesis

- hardcoding behavior to fix incorrect outputs

Fix root cause, not symptoms.
